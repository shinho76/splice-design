## 3. 볼트배치별 활성 Path 매트릭스 (검증판)

배치 정의: **1열 = `m=2`**(웨브 CL 상·하 각 1 게이지선), **2열 = `m=4`**(상·하 각 2 게이지선).
**엇모(staggered)는 이 축과 직교**한다(§3 말미). 아래는 원본 도판·AISC J4.3 재검증 결과다.

> **활성 규칙(원리)**: block shear 블록이 성립하려면 *전단면(하중 평행) + 인장면(하중 수직)* 이
> 실제 판/부재 경계에서 닫혀야 한다. **밴드별 U(2전단면)는 그 밴드에 게이지선 2개**가 있어야
> 성립 → **m=4 전용**. 밴드별 L(1전단면)·전폭/전열 U는 게이지선 1개로도 성립 → **1열부터 활성**.

### 외부 이음판 (연속판, 웨브 갭을 가로지름) — 소요력 `halfOuter`(면적비례, §6)
| 배치 | `cols`(예) | 활성 Path | 비고 |
|---|---|---|---|
| **1열 (m=2)** | `[±g1/2]` | **1, 2a, 2b** | 판이 CL을 가로질러 연속 → 상·하 게이지선 2개로 **전열 U(2a) 성립** |
| **2열 (m=4)** | `[±g1/2, ±(g1/2+g2)]` | **1, 2a, 2b, 3** | 밴드당 게이지선 2개 → **밴드별 U(3) 추가** |

### 내부 이음판 (웨브 양측 분리된 쌍판 ×2) — 소요력 `halfInner`(쌍 합계, `plates=2`)
| 배치 | 활성 Path | 비고 |
|---|---|---|
| **1열 (m=2)** | **4 (L만)** | 판당 게이지선 **1개** → U(5a) 성립 불가. **외첨판과의 결정적 차이** |
| **2열 (m=4)** | **4, 5a, 5b** | 판당 게이지선 2개 → 전열 U(5a) + 대체 순단선(5b) |

### 거더 플랜지 (부재) — 소요력 `Pf`(플랜지 전력, `plates=1`)
| 배치 | 활성 Path | 비고 |
|---|---|---|
| **1열 (m=2)** | **6(좌)/7(우)** (전폭 블록) | 전폭 인장 + 양 연단 전단은 게이지선 수 **무관** → 1열부터 활성 |
| **2열 (m=4)** | **6/7 + 8(좌)/9(우)** (클러스터 U) | 클러스터(밴드) U는 밴드당 게이지선 2개 필요 → **8/9는 m=4에서 추가** |

> 6/7·8/9의 좌/우는 **좌거더·우거더(동일 기하, 대칭)**. 대칭 단면이면 한쪽 산정 + "타측 대칭",
> 비대칭(양측 단면·소요 상이)이면 **양측 모두 산정**. **m 종속 항목은 8/9(클러스터)이지 7이 아님**.

### 웨브 이음판 (×2) — 소요력: V=`Vu`, H=축력·웨브모멘트 수평성분(신설)
| 배치 | 활성 Path | 비고 |
|---|---|---|
| **1열/2열 공통** | **1 (V, 수직전단 블록)** | 항상. 소요력 `Vu`. 코드 WP1(`vertical`, `plates=2`) |
| **모멘트/축력 접합 시 추가** | **2 (U, H), 3 (L, H)** | 웨브가 축력 `N_u`·웨브분담모멘트 `M_web`의 **수평성분**을 받으면 지배 가능 → **신설 검토**(§7 C-1) |

### 거더 웨브 (부재) — 소요력: V=`Vu`(코드 WM2), H=수평성분(신설)
| 배치 | 활성 Path | 비고 |
|---|---|---|
| **1열/2열 공통** | (V) 수직전단 블록 | 코드 WM2(`Vu`, `plates=1`). *부재 웨브는 연속 → V 블록만 유의미* |
| **모멘트/축력 접합 시 추가** | **4(좌)/5(우)** (H) | 원본 도판은 거더웨브를 **H(모멘트·축력)** 로만 도시 → H 블록 **신설 검토** |

### 엇모(staggered) — 위 1열/2열과 **직교하는 별도 축**
- 엇모는 **활성 Path 집합을 바꾸지 않는다.** 각 Path의 **인장 순단면적에만 `s²/4g`(B4.3b) 가산**
  (`geometry.ts::stagAdd`, `netAreaStag`). Path 번호는 정렬 배치와 동일하게 부여.
- 즉 "1열↔2열"(게이지선 개수 → Path 집합)과 "정렬↔엇모"(순단면 보정)는 **독립 2축**이다.
- 원본 도판의 파단선이 엇모에서 사선으로 보이는 것은 볼트 어긋남 때문이며, **새 Path가 아니다.**

> **주의 2건(정정):**
> 1. **엇모는 Path가 아니다.** 이전판이 엇모→Path 3, 내첨판 엇모→"Path 5(지그재그)"로 적은 것은 오기.

> 2. 코드의 `C(전열 U)`는 부재 웨브에 대해 **Vu 수직블록**을 산정한다. 원본 도판의 거더웨브
>    Path **4/5는 H(모멘트·축력)** 블록으로, **현재 코드에 미구현**(§7 신설 대상).

> 앱은 A/B/C/D를 **전 요소 공용**하지만 PDF는 **요소마다 다른 번호** → 매핑은 **요소 컨텍스트 종속**

> 1:1이 아니며, **진짜 밴드 분할(2b/3, 8/9)** 은 §7 Phase C에서 명시화한다.

## 4.5 검증 결과 — 사용자 1열/2열 Path 표 정오 판정 (AISC 360-16 J4.3)

원리: J4.3 `φRn = φ[min(0.6FuAnv, 0.6FyAgv) + Ubs·Fu·Ant]`. **각 요소·각 배치에서 성립 가능한
모든 블록(전단면+인장면 폐합)** 을 열거하고 최대 DCR을 지배로 취한다. 블록 성립 여부는
**해당 밴드/판의 게이지선 개수**가 좌우한다.

| # | 사용자 표 항목 | 판정 | 근거 (J4.3 블록 성립성) |
|---|---|---|---|
| Q1 | 외첨판 **1열에서 Path 3 제외** | **정** | Path 3=밴드별 U는 밴드당 게이지선 2개 필요. 1열은 밴드당 1개 → 미성립. m=4 전용 맞음. |
| Q2 | 외첨판 **1열에 Path 2b 포함** | **정** | Path 2b=밴드별 L은 밴드당 게이지선 1개로 성립(CL측 전단 1 + 외열 인장). 1열도 유효. |
| Q3 | 내첨판 **1열 = Path 4(L)만** | **정** | 내첨판은 웨브 양측 **분리 쌍판** → 1열이면 판당 게이지선 1개 → U(5a) 미성립, L(4)만. 외첨판은 CL을 가로지르는 **연속판**이라 1열에도 전열 U(2a) 성립 — 이 차이가 핵심. |
| Q4 | 거더플랜지 **2열=6,7 / 1열=6** | **오** | 6/7은 **좌·우 거더**(동일 기하)로 m 무관·항상 적용. m 종속 항목은 **클러스터 U인 8/9**. 정정: **1열=6·7(전폭)**, **2열=6·7 + 8·9**. 전폭 블록은 1·2열 모두 적용. |
| Q5 | 웨브 = **Path 1(V)만** | **불충분** | 모멘트/축력 접합에서 웨브가 축력·웨브분담모멘트의 **수평성분**을 받으면 Path **2·3(H)** 가 지배 가능(J4.3은 관련 한계상태 전부 요구). **H 블록 추가 권고**(소요력=웨브 수평분담). 거더웨브 **4/5(H)** 도 동일 — 사용자 표에 누락. |
| Q6 | 소요력 `Pu/2`(외/내첨판) | **부분오(안전측 아님)** | 실제는 판 총단면적 비례분배 `halfOuter`/`halfInner`(코드 `demand.ts` 채택). `Pf/2`는 면적 동일 시에만 일치하고, **면적 큰 판에서는 과소평가(비보수)**. 거더플랜지 `Pu(=Pf)`, 웨브 `Vu`는 타당. |

**바로잡은 핵심 3건**
1. **거더플랜지(Q4)**: `6/7`은 좌우거더 대칭쌍 → m 무관 상시. 배치 종속 추가분은 **8/9(클러스터 U)**.
   전폭 블록(6/7)은 **1열·2열 공통 적용**.
2. **웨브 H블록(Q5)**: 웨브 이음판 **2·3(H)**, 거더웨브 **4/5(H)** 를 모멘트/축력 접합에서 검토대상에
   포함(현재 엔진은 V 블록만 → §7 C-1 신설). 소요력은 웨브 수평분담(`N_u` + `M_web`/유효깊이).
3. **소요력(Q6)**: 외/내첨판은 `Pf/2`가 아니라 **면적비례 `halfOuter`/`halfInner`** 사용(엔진 기채택).
   `Pf/2`는 비보수 가능 → 계산서 소요력 컬럼은 면적비례값으로 표기.

## 5. Phase A — 명명 마이그레이션 (표시 전용, 엔진 수치 불변)

**목표**: 라벨을 `Case X · Mode Y` → `Path N`으로. φRn·지배·골든테스트 **불변**.

- **타입** (`aisc/types.ts`)
  - `BlockCase.mode?: string` → **`path?: string`** 로 대체.
  - `BlockShearGeom`에 **`region`** 추가: `'outer'|'inner'|'member-flange'|'web-plate'|'member-web'`.
- **엔진** (`aisc/geometry.ts`)
  - `BS_MODE` 제거. **`PATH_OF: Record<region, Record<caseKey, string>>`** 룩업 신설(위 §4 표).
  - `blockShear(p)`에 `p.region` 전달받아 `mk(...)`가 `path` 채움. `caseKey`는 내부 상수(`'C'|'A'|'B'|'D'|'single'`).
- **호출부**: `flange.ts`(FP5 outer / FI5 inner / FM5 member-flange), `web.ts`(WP1 web-plate / WM2 member-web)에 `region` 지정.
- **계산서**: `AiscDetailReport.tsx::BlockCaseTable`, `flange.ts::bsDetail`, `web.ts` 라벨 `Path N`으로 교체 + 요소 상단 **Path 범례** 1줄.
- **회귀**: 수치 무변 → 골든(`validate.ts`) 영향 없음. 스냅샷/라벨 텍스트만 갱신.

## 6. Phase B — 도해(CheckFig) PDF 기하로 재작도

- `CheckFig.tsx::BsPanel` 파단선을 **Path별 기하 함수**로 재작성:
  - `L`(1전단+1인장) · `U`(2전단+1인장) · `분할U`(밴드별) · `지그재그`(엇모, **s²/4g 사선 해치 — 기구현 유지**) ·
    `전폭 부재블록`(6/7) · `수직전단`(웨브 V) · `축력 U·L`(웨브 H).
- 하중 화살표: 플랜지=**H**(수평), 웨브 Path1=**V**(수직)·Path2/3=**H**. 자유단 체크무늬(옵션).
- 좌/우 거더 대칭(6/7·8/9·4/5): **좌거더 1도해 + "우거더 대칭" 주석**(결정 4).
- 볼트배치 자동 분기: `region`+`m`(1열/2열)+`staggered`로 그릴 Path 집합 결정(§3 매트릭스).
- 3D/DXF 정합(`nHi/nLo`, off=45, 90피치, `flangeColumns`) 유지 — 도해 좌표는 기존 `stagOf` 재사용.

## 7. Phase C — 엔진 신설 (수치 변동 O)

### C-1. 웨브 이음판 H 블록 (Path 2·3) — **신설**
- 현재 `web.ts::WP1`은 **수직전단(V)** 기준(`vertical:true`)만 산정.
- 추가: **수평(H) 블록전단** — 웨브가 분담하는 **모멘트/축력의 수평성분**에 대한 block shear.
  - Path 2 = U(전단 수평 상·하 + 인장 수직 중앙열), Path 3 = L(외측 수평 전단 + 외측열 수직 인장).
  - 기하: 웨브판 볼트 `colsAxis`(수직 볼트열)·`nVert`(열당 볼트수)로 `blockShear` 재사용하되 **하중축 90° 회전**(현 `vertical` 플래그의 반대).
- **소요력(H) 정의 — 확인 필요 1건**: `DemandSet`의 웨브 성분(`Vu`, `MuxWeb`, `e`)으로부터 수평 블록 소요를 정의.
  - 후보(권장): 모멘트 분담 `MuxWeb`에 의한 **수평 짝힘** `H_web ≈ MuxWeb / (수직 볼트군 유효깊이)` 또는 최외곽 볼트 탄성 수평분력.
  - → **엔진 착수 직전 steel-connection-engineer 검토로 확정** 후 반영.

### C-2. 거더 플랜지 전폭 블록 (Path 6/7) — 신설/확인
- 부재 플랜지 **전폭 인장 + 양 연단 전단** 블록을 `FM5`에서 별도 산정(현재 `halfWidth=B/2` U블록이 이를 포함하는지 확인 후 보완).

### C-3. a/b 대체 순단면 (Path 2b/5b) — 명시화
- "어느 볼트열을 인장 순단선으로 보는가"의 **대안 2종을 각각 산정 → min 지배**로 명시(현 `D/B` 로직 일반화).

### C-4. 지배·표시
- 신설 Path도 `blockShearGovern`의 DCR 비교에 편입(요소별 `plates` 배율·`frac` 유지).
- 신설로 지배가 바뀔 수 있으므로 **대표 단면 회귀 스냅샷 재검토**(골든 KBC 경로는 불변).

## 9. 작업 순서 & 산출물
1. **A** 타입·`PATH_OF`·호출부 `region` → 계산서 라벨/범례. (회귀 무변)
2. **B** CheckFig Path 기하 재작도 + 배치 자동분기 + 좌/우 대칭 주석.
3. **C-1** 웨브 H 소요력 정의 확정(엔지니어 검토) → 웨브 H 블록 신설.
4. **C-2/C-3** 거더 전폭·a/b 대체 순단면 명시화.
5. **검증**: `tsc`, 골든(`validate.ts`) 불변 확인, 대표 단면(정렬/2열/엇모, 보/기둥) 도해·수치 스냅샷 대조, 브라우저 육안 확인.
6. **산출**: 상세계산서 Path 표기 + Path 도해, DXF/3D 볼트배치 정합 유지.
