# AISC 360-16 엔진 재작성 계획

참고: https://github.com/shinho76/splice-design_aisc360-16
목표: **KBC-09는 그대로 두고**, AISC 360-16 경로를 참고 엔진의 검토 체계로 재작성.
단위: **SI(mm·kN·MPa)**. 재료: 앱 강종(SN355 등) + A992/A572 매핑. 배치: 앱(편람) 배치 입력.

> 참고 엔진은 imperial(ksi·kip·in), 자체 W-Shape·4열 고정배치 기반이라 **1:1 수치 재현이 목표가 아니라 검토 "커버리지·방법론" 이식**이 목표. (골든은 참고 PDF 대신 앱 수계산으로 검산)

## 3. 데맨드 (`core/demand.ts` 단일 소스)
- 플랜지력 `Pf = M/(d−tf) + P/2` (couple arm = d−tf). 각 판 Pf/2, 볼트 full Pf.
- 웨브: `Vu`, 편심 모멘트 `Mu,x = Vu·e` (판이 휨 흡수, 볼트 IC감소 없음), `Mu,y` 출력.
- 강도비 모드: 100%=`φMn=0.9FyZx`, `φVn=0.9·0.6FyAw·Cv1`(G2.1) → Mu,Vu 도출.

## 4. 옵티마이저 (사전식, `optimize.ts`)
- 목적(오름차순): ① 볼트수 최소 → ② 판두께 최소.
- `for n: for t: RunAllChecks; if allPass return {n,t}` (첫 만족=최적).
- 종료: 물리한계(최대두께 NG / 웨브 편심 발산).
- 출력: **탐색이력**(n·t·실패항목·DCR).
- 볼트수로 개선 안됨: FM3(항복)·WM1(전단항복) → 부재/판두께로만.

## 5. 기하·재료
- 순단면 `An = (W − nHoles·dh)·t`, `dh = d + 표준여유(STD d+2mm)`.
- 재료: A992(Fy345/Fu450), A572(345/450); 앱 SN355 등 유지.
- CalcStep: 식·대입·중간값·φ·판정 반환(추적성).

## 6. 단계 (Phase)
1. 기반: 상수·데맨드·기하 (SI)
2. 플랜지 FB/FI/FP/FM + 블록전단 전 Case
3. **웨브 스플라이스 WB/WR/WP/WI/WM (신규)**
4. 사전식 옵티마이저 + 이력
5. CalcStep 계산서 + **DXF 상세 개선(디테일러 가독성)**

KBC-09 경로·골든은 전 과정 불변.
