# 볼트직경 × 판두께 자재비 최소화 — 타당성·설계 기록 (보류)

> **상태: 검토·시제 구현 완료 후 사용자 요청으로 코드 취소(revert). 본 문서는 기록 보존용.**
> 필요 시 이 설계대로 재구현 가능. (steel-connection-engineer 검토 반영)

## 1. 요구
"현재 설계조건에서 **볼트직경·판두께(내·외판 동일)만** 변경하여 **자재비 최소**가 되도록 반복 연산·수렴한
결과를 보여줘. 가설: 볼트직경↑ → 수량↓ → 이음판↓ → 강재↓ → 경제적."

## 2. 타당성 판정: **가능** (엔진 코어 불변, 얇은 완전열거 래퍼로 충분)
기존 자산이 뼈대를 이미 제공:
- `engine.ts` `designConnection(cond, sec, forceDia)` — **볼트직경 고정 설계**.
- `aisc/optimize.ts` `aiscOptimize` — 직경 고정 시 **판·볼트를 DCR≤1로 최소화**(결정적) + 부분강도캡핑.
- `quantity.ts` `quantityOf` — 실물량(외2·내4·웨2 정합)·볼트개수·볼트중량.

## 3. 확정 설계 (steel-connection-engineer 검토)
- **완전열거(exhaustive), "수렴" 불필요**: 직경 M16~M30 6종 × 판두께 표준격자는 이산·유한 →
  각 직경 `aiscOptimize` 1회(6회) → 전역최소 결정적 확정.
- **목적함수 = 판강재비 + 볼트비**(볼트비 필수 — 강재중량 단독은 큰 직경으로 자기충족 편향).
  - 단가(사용자 확정): 강재제작(강재+드릴링) **1,700원/kg**, 볼트 **4,500원/kg**(중량) 또는 **6,000원/EA**(개당).
- **내·외판 동일**(`equalPlateT=true`). **부재지배(부분강도) 후보 허용**(순수강도 우선).
- **기하 유효성 필터 필수**: `forceDia`는 볼트명만 바꾸고 H형강 게이지·판폭은 공칭 고정 →
  **횡연단 ≥ 최소연단[d](J3.4M)** 위반 직경을 `기하불가`로 컷.

## 4. 핵심 발견 (실측)
- **비용은 비단조(U자형)** — 최소가 **중간 직경**인 경우가 흔함. 예 H-612×202(중량모델):
  M16 428,127 → **M20 332,913(최소)** → M22 361,376 → M30 440,621.
- **최적 직경이 볼트단가 모델에 좌우**:
  | 단면 | 중량(4,500/kg) | 개당(6,000/EA) |
  |---|---|---|
  | H-500×200 | M20 | M30 |
  | H-612×202 | M20 | M27 |
  | H-346×174 | M16 | M22 |
  → **사용자 가설("큰 직경 유리")은 개당 모델에서 성립**, 중량 모델에선 볼트비 급증으로 반증.
  실무 단가에 맞는 모델 선택 필요(UI 토글로 병기).

## 5. 시제 구현물 (취소됨 — 재구현 참고)
- `src/engine/aisc/optimizeDia.ts` — `optimizeByDia(sec, cond, unit)` + `pickBest(cands, mode)`.
  DIA=[16,20,22,24,27,30], `DiaCandidate{status: ok|partial|geomNG|fail, costTotal, costTotalEa, …}`.
- `src/components/DiaOptimizePanel.tsx` — 후보비교표 + 볼트단가 모델 토글 + best 하이라이트.
- `App.tsx` — 선택부재 `₩ 자재비최적` 버튼(AISC/KDS 한정) → 패널.
- 검증: tsc·vite build EXIT 0, 브라우저 실동작 확인(비단조·토글·기하필터 정상).

## 6. 재개 시 고려
- 단가를 상수 고정 말고 **입력 패널 + 민감도**로 노출(강재:볼트 비에 따라 최적 직경 변동).
- 부재지배 시 직경 무관 상한 → 판·볼트 최소로 환원(큰 직경 편향) 명시.
- 전 부재 일괄 적용(각 부재 최적 직경) 옵션은 성능(부재수×6회) 고려.
