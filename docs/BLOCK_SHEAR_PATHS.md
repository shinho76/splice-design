# 블록전단(Block Shear) 파단 Path — 재구성 모델 & 웹 구현 계획

> 근거: AISIsplice Appendix C 파단선 도해(**빗금 = 탈락블록**). 상세계산서/도해의 탈락블록
> 영역을 원 첨부와 1:1로 맞추기 위한 기준 문서. 시각 확인: `docs/파단선/paths/index.html`.

## 0. 표기 규약
| 기호 | 의미 | 강도항 |
|---|---|---|
| 🔴 빨강 실선 | **전단 파단면** (하중방향 ∥, 게이지선 따라) | `min(0.6·Fu·Anv, 0.6·Fy·Agv)` |
| 🔵 파랑 점선 | **인장 파단면** (하중방향 ⊥) | `Ubs·Fu·Ant` |
| 🟡 빗금 | **탈락(뜯김) 블록** — 실제로 떨어져 나가는 판 영역 | — |
| ℄ | 이음면(splice joint) · 자유단 | — |

`φRn = φ[min(0.6FuAnv, 0.6FyAgv) + Ubs·Fu·Ant]`, φ=0.75. Ubs = 1.0(인장 균등)·0.5(비균등, 단일 전단 L블록).

## 1. 요소·좌표 모델
- **플랜지 평면**: x = 하중축(Pf, 자유단 0 → 이음 ℄), y = 폭(웨브 CL = y=0). 게이지선 = y = ±(gauge).
  - 외부 이음판 = 전폭 1매(y ∈ [−B/2, B/2]).
  - **내부 이음판 = 웨브 양측 2매를 동시 고려**(웨브 중앙 바 표기). 각 판은 반대편 판과 독립 파단.
  - 부재 플랜지(Girder) = 전폭, 웨브 위치 표기.
- **웨브 입면**: u = 춤(하중 Vu, 아래), v = 축방향. **이음면 기준 한쪽 절반만** 검토(볼트열 1열 × nVert행 → 수직 전단 1면 + 최하단 수평 인장).

## 2. 배치별 Path 카탈로그 (탈락블록 정의)

### 2.1 외부 이음판 (Outer) — 게이지선 ±a(1열=2선, 2열/엇모=4선: ±aIn,±aOut)
| Path | 전단면 | 인장면 | 탈락블록(빗금) | Ubs | 적용 |
|---|---|---|---|---|---|
| **1** (L) | 1면 = 최외곽선(한쪽) | 최외곽선↔반대편 최외곽선(across) | 두 최외곽선 사이 밴드 | 0.5 | 1·2·엇모 |
| **2a** (U·내측인장) | 2면 = 양 최외곽선 | 두 선 사이(내측) | 최외곽선 사이 밴드 | 1.0 | 1·2·엇모 |
| **2b** (U·외측인장) | 2면 = 양 최외곽선 | 각 선 → 판 외측 연단 | **바깥쪽 2밴드**(선↔연단) | 1.0 | 1·2·엇모 |
| **3** (밴드분할 U) | 4면 = ±aIn,±aOut | 각 밴드 [aIn,aOut] | 상·하 2밴드(내·외선 사이) | 1.0 | 2·엇모(m≥4) |
| 1a/1b·2c | 엇모 지그재그 분기 | 〃 (s²/4g 순단면 보정) | 〃 | 0.5/1.0 | 엇모 |

### 2.2 내부 이음판 (Inner) — **웨브 양측 2매 동시**
| Path | 전단면(판당) | 인장면 | 탈락블록 | Ubs |

## 4. 웹 구현 계획 (엔진 → CheckFig)
1. **기하 카탈로그 분리** — `geometry.ts`의 범용 `blockShear()` 대신, 요소×배치별 Path를
   **명시적 블록 정의**(전단선 y[], 인장구간, 밴드 폴리곤)로 테이블화. (본 문서 §2 = 사양)
2. **내부판 2매 모델** — `flange.ts` FI5: 현재 단일 중앙 스트립(cols=[0]) → **상·하 2판**(웨브 바 포함),
   각 판 독립 Path 4/5, `plates:2` 합산 유지. 엇모 시 내부판도 `staggered:true`.
3. **웨브 한쪽 절반** — `web.ts` WP1: `colsAxis` 양측(±)이 아니라 **한쪽 절반**(1열 × nVert)으로
   블록 산정. 도해도 절반만.
4. **CheckFig 렌더** — 탈락블록을 **빗금 폴리곤**(해석적 45° 클리핑)으로, 전단=빨강 실선·인장=파랑
   점선. Path별 밴드 폴리곤은 §2 정의를 그대로 사용(범용 `fracture()` 대체).
5. **검증** — 3개 샘플 도해를 원 첨부와 대조(`docs/파단선/paths/`). DCR·φRn은 기존 엔진 값 유지,
   **탈락블록 표기만** 교체.

## 5. 확정 사항 (사용자 검토 반영)
- **Outer Path 1 인장면 = 외측 연단** (across 아님). 탈락블록 = 외측 1밴드(외곽선↔연단).
- **Inner Path 4 인장면 = 판 외측 연단.** 탈락블록 = 각 내부판의 외측 밴드(게이지선↔판 외연).
- **웨브 = 이음면 기준 한쪽 절반**만(대칭).
- **H-700(엇모) = 경사(stepped) 파단선.** 인장면이 엇갈림 볼트를 계단형으로 통과 →
  첨부 sub-case 반영: Outer **1a·1b·2a·2b·2c·3**, Inner **4a·4b·5a·5b**, Girder **6a·7·8**.
- 본 작업은 **도해(CheckFig 시각화)만** — 엔진 검토식(DCR·φRn)은 미변경.
